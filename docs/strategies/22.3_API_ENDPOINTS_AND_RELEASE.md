# M22 Phase 3 — API Endpoints and Release

Status: Approved; §3 next.
Parent: [M22](../milestones/22_LINE_ITEMS_DEVELOPER_API.md), Phase 3.

Goal: a developer creates, sends, reads, edits, and deletes invoices through the API exactly as [API.md](../API.md) describes, and can reconcile an order by polling; then it ships to prod.
